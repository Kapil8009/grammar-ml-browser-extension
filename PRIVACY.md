# Privacy policy

Grammar ML processes text only to request grammar corrections from the backend URL configured by the user.

- The extension does not include analytics, advertising, or tracking code.
- Text is sent only when the user invokes correction, or after typing stops if the user explicitly enables automatic checking.
- The backend URL and non-secret preferences may sync through the browser's extension settings.
- The optional API key is stored in local extension storage and is not intentionally synced.
- The project does not persist submitted text. A hosting provider, reverse proxy, or custom deployment may keep network or application logs; the operator is responsible for its own retention policy.
- The extension needs page access to read and replace text in editable fields, and network access to contact a user-configured HTTPS backend.

Do not submit passwords, payment data, health records, or other sensitive content unless you trust and control the configured backend and its hosting provider.
